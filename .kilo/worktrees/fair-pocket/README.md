## 🌟 ویژگی‌های معکوس‌شده از Adobe Connect

این پروژه بر اساس تحلیل دقیق تجربه کاربری ادوبی کانکت از صفر بازنویسی شده است:

* **موتور چیدمان و پادها (Pod Layout Engine):**
  * بوم ۲ بعدی انعطاف‌پذیر با قابلیت جابجایی (Drag)، تغییر اندازه (Resize)، تمام‌صفحه (Maximize) و بستن پادها.
  * نوار چیدمان‌های پیش‌فرض سمت راست: **Sharing** (اشتراک‌گذاری)، **Discussion** (بحث و گفتگو) و **Collaboration** (همکاری و کار گروهی).
  * حالت **Prepare Mode** برای استاد/مدیر (تنظیم خلوت چیدمان قبل از انتشار همگانی).
* **پاد حاضرین و مدیریت دسترسی‌ها (Attendee Pod):**
  * تفکیک سلسله‌مراتبی به سه گروه: **Hosts** (مدیران)، **Presenters** (ارائه‌دهندگان) و **Participants** (شرکت‌کنندگان).
  * قابلیت **دست بالا بردن (Hand Raise)** با صدای زنگ، شمارنده زنده و امکان ریست دسته‌جمعی توسط Host.
  * وضعیت‌های تعاملی: موافق (Agree)، مخالف (Disagree)، ترک موقت (Step Away)، تشویق (Applause).
  * اتاق انتظار و صف تایید ورود (Waiting Room / Admission Queue) برای ورود مهمان‌ها.
  * کنترل جزء‌به‌جزء دسترسی میکروفون، وبکم، تخته، چت و اخراج کاربر.
* **پاد اشتراک‌گذاری (Share Pod):**
  * **اشتراک صفحه (Screen Share):** تصویر روان به همراه صدای سیستم با WebRTC.
  * **شبکه وبکم‌ها (Webcam Grid):** تصویر وبکم ارائه‌دهنده و سایر حاضرین مجاز.
  * **تخته وایت‌برد وکتوری سنکرون (Whiteboard):** ابزارهای قلم، ماژیک فسفری، خط، فلش، مستطیل، دایره، درج متن، پاک‌کن، پالت رنگ، چندصفحه‌ای و پاک‌سازی.
  * **نمایش اسناد و اسلاید (Document/PDF Viewer):** اشتراک اسناد به فرمت Data URL، ورق زدن همگام اسلایدها و زوم.
* **پاد گفتگو (Chat Pod):**
  * تب عمومی (Everyone)، تب ویژه کادر مدیریت (Hosts) و گفتگوی خصوصی ۱ به ۱ (Private PM).
  * افکت‌های صوتی داخلی با Web Audio API بدون نیاز به دانلود فایل صوتی از خارج.
* **پاد نظرسنجی (Poll Pod):**
  * پرسش‌های چندگزینه‌ای (تک جوابی / چند جوابی) و پاسخ تشریحی/کوتاه.
  * نمایش زنده درصد آرا به همراه کلید انتشار عمومی نتایج (Broadcast Results).
* **پاد یادداشت‌ها (Notes Pod):**
  * یادداشت‌برداری گروهی همزمان با قابلیت خروجی گرفتن فایل متنی (Export .txt).
* **اتاق‌های تفکیک‌شده (Breakout Rooms):**
  * تقسیم خودکار یا دستی کاربران به اتاق‌های چندگانه، پیام سراسری استاد به همه اتاق‌ها و اتمام بریک‌اوت.

## 🛡️ معماری سیستم و سازگاری با شبکه ایران

1. **انتقال صوت و تصویر (WebRTC Mesh / Presenter Broadcast):**
   * برای جلوگیری از هزینه‌های سرور مدیا، ارتباط صوتی و تصویری استاد به دانشجویان به‌صورت مستقیم از طریق WebRTC منتقل می‌شود.
   * لیست سرورهای STUN افزونه‌ای و مقاوم (`Google`, `Cloudflare`, `Twilio`) برای عبور از NATهای مخابرات ایران تعبیه شده است.
2. **ارتباط داده و استیت بر بستر WSS (پورت 443):**
   * تمامی دستورات پادها و سیگنالینگ روی وب‌سوکت امن رمزنگاری‌شده عبور می‌کنند تا از فیلترینگ DPI پروتکل‌های غیر وب در امان باشند.
3. **عدم وابستگی به CDNهای خارجی:**
   * صداهای سیستم توسط Web Audio API روی مرورگر سنتز می‌شوند تا در صورت قطعی اینترنت بین‌الملل نیز سیستم بدون نقص کار کند.

## ⚡ آموزش استقرار روی Cloudflare Workers (پلن رایگان)

کلودفلر ورکر به دلیل داشتن پاپ‌سایت‌های متعدد، برای سیگنالینگ و مدیریت استیت اتاق‌ها ایده‌آل و **۱۰۰٪ رایگان** است (تا ۱۰۰ هزار درخواست در روز).

### پیش‌نیازها:
* حساب کاربری در [Cloudflare](https://dash.cloudflare.com/)
* نصب [Node.js](https://nodejs.org/) نسخه 18 به بالا

### گام ۱: دریافت و نصب پکیج‌های بک‌اند
```bash
git clone https://github.com/your-username/classroomflare.git
cd classroomflare/backend
npm install
```

### گام ۲: ورود به حساب کلودفلر
در ترمینال دستور زیر را اجرا کنید تا صفحه لاگین کلودفلر در مرورگر باز شود:
```bash
npx wrangler login
```

### گام ۳: تست محلی ورکر
برای بررسی کارکرد محلی بدون نیاز به اتصال به اینترنت:
```bash
npm run dev
```
ورکر روی آدرس `http://localhost:8787` فعال می‌شود. وب‌سوکت در آدرس `ws://localhost:8787/ws` در دسترس است.

### گام ۴: دیپلوی روی کلودفلر
تنها با یک دستور ورکر خود را روی دامنه رایگان کلودفلر مستقر کنید:
```bash
npx wrangler deploy
```
در پایان ترمینال آدرسی مشابه زیر به شما می‌دهد:
```
https://classroomflare-backend.<your-subdomain>.workers.dev
```
آدرس وب‌سوکت شما برای اتصال فرانت‌اند به‌صورت زیر خواهد بود:
```
wss://classroomflare-backend.<your-subdomain>.workers.dev/ws
```

## 🇮🇷 آموزش استقرار روی سرویس ابری چابکان (Chabokan.net)

[چابکان (Chabokan.net)](https://chabokan.net/) یک پلتفرم ابری سرورلس و کانتینری (PaaS) در داخل کشور است.
استقرار ClassroomFlare روی چابکان مزایای فوق‌العاده‌ای دارد:
* **پینگ تک‌رقمی (زیر ۱۰ میلی‌ثانیه):** برای کاربران داخل ایران به دلیل استقرار در دیتاسنترهای داخلی.
* **ترافیک داخلی و نیم‌بها:** هزینه‌های اینترنت اساتید و دانشجویان به‌صورت نیم‌بها محاسبه می‌شود.
* **بدون مشکل تحریم و فیلترینگ:** بدون نگرانی از اختلالات UDP یا فیلترینگ کلودفلر.

نسخه اختصاصی چابکان در پوشه `chabokan/` و ریشه پروژه با یک **Dockerfile چندمرحله‌ای (Multi-stage)** آماده شده است که کل اپلیکیشن فرانت‌اند و بک‌اند را در قالب **یک کانتینر سبک و مستقل** اجرا می‌کند.

---

### روش استقرار با داکر در چابکان (ساده‌ترین و پیشنهادی)

#### مرحله ۱: ثبت‌نام و ورود به چابکان
1. وارد پنل کاربری خود در [Chabokan.net](https://chabokan.net/) شوید.
2. روی دکمه **«ایجاد سرویس جدید»** کلیک کنید.

#### مرحله ۲: انتخاب سرویس داکر (Docker Service)
1. نوع پلتفرم را **Docker** یا **برنامه بر پایه گیت (Git App)** انتخاب کنید.
2. مخزن گیت پروژه خود را متصل کنید (یا از طریق رابط کاربری چابکان سورس را ارسال نمایید).
3. مسیر Dockerfile را برابر با `Dockerfile` ریشه پروژه قرار دهید.

#### مرحله ۳: تنظیم متغیرهای محیطی و پورت
* در بخش **تنظیمات پورت (Port Mapping)**:
  * پورت ورودی کانتینر: `3000`
* در بخش **متغیرهای محیطی (Environment Variables)**:
  ```env
  PORT=3000
  NODE_ENV=production
  ```

#### مرحله ۴: تنظیم دامنه و SSL رایگان
1. در پنل چابکان، زیردامنه رایگان چابکان (مانند `classroom.chabokan.app`) را دریافت کنید یا دامنه اختصاصی خود را متصل نمایید.
2. گزینه **فعال‌سازی گواهی SSL (HTTPS)** را فعال کنید تا چابکان به‌صورت خودکار گواهی معتبر Let's Encrypt صادر کند.
3. روی دکمه **«راه‌اندازی سرویس»** کلیک کنید.

پس از پایان بیلد، کل کلاس روم با فرانت‌اند React و وب‌سوکت پایدار بر روی دامنه شما فعال خواهد بود. وب‌سوکت به‌صورت خودکار روی مسیر زیر متصل است:
```
wss://classroom.chabokan.app/ws
```

---

### تست محلی نسخه چابکان با Docker Compose
برای تست این نسخه در سیستم خودتان:
```bash
docker compose up --build
```
سپس مرورگر را باز کرده و به آدرس [http://localhost:3000](http://localhost:3000) بروید.

## 💻 اجرای نسخه تحت وب (Web Client)

اگر می‌خواهید فرانت‌اند را به‌صورت جداگانه اجرا یا سفارشی‌سازی کنید:

```bash
cd frontend
npm install
npm run dev
```
مرورگر را باز کرده و به آدرس `http://localhost:1420` بروید.

در پنجره ورود:
* **Your Display Name:** نام نمایشی شما.
* **Room ID:** نام کلاس (مثلاً `math101` یا `class1`).
* **Join As:** انتخاب نقش شما (مهمان/دانشجو یا Host/استاد).
* **Cloudflare / Chabokan URL:** آدرس وب‌سوکت سرور چابکان یا کلودفلر ورکر (پیش‌فرض: `ws://localhost:8787/ws` یا `wss://your-domain/ws`).

برای بیلد استاتیک فرانت‌اند جهت آپلود در هاست‌های اشتراکی یا CDN:
```bash
npm run build
```
فایل‌های آماده در پوشه `frontend/dist` قرار می‌گیرند.

## 🖥️ تولید خروجی نصبی ویندوز (Tauri v2)

اپلیکیشن ویندوز با فریمورک پیشرفته **Tauri v2** بسته‌بندی شده است. برعکس الکترون که بالای ۱۵۰ مگابایت حجم دارد و مصرف رم بالایی دارد، نسخه ویندوز این پروژه از موتور بومی **WebView2 ویندوز** استفاده می‌کند و فایل نصبی آن **زیر ۱۵ مگابایت** است.

### پیش‌نیازها:
1. سیستم‌عامل ویندوز ۱۰ یا ۱۱.
2. نصب [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/).
3. نصب ابزار [Rust](https://rustup.rs/) (با اجرای دستور `rustup default stable`).

### اجرای حالت توسعه ویندوز:
```bash
cd frontend
npx tauri dev
```
پنجره اختصاصی دسکتاپ ویندوز باز خواهد شد.

### تولید فایل نصبی نهایی (.exe و .msi):
```bash
cd frontend
npx tauri build
```
خروجی نصبی کامپایل‌شده در مسیر زیر ایجاد می‌شود:
```
frontend/src-tauri/target/release/bundle/msi/ClassroomFlare_1.0.0_x64_en-US.msi
```

│   │   ├── components/
│   │   │   ├── layout/            # نوار ابزار بالا، سایدبار چیدمان، کانتینر پادها
