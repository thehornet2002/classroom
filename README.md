## 🌟 ویژگی‌ها و قابلیت‌های سامانه

* **انتقال صوت و تصویر فوق‌سریع (UDP/WebRTC):** ارتباط مستقیم صوتی و تصویری با کمترین تاخیر (Low Latency) با استفاده از UDP.
* **تغییر دلخواه پروتکل به ازای هر اتاق (UDP vs WS):** قابلیت انتخاب پروتکل انتقال برای **صدا**، **تصویر** و **تخته/داده‌ها** هنگام ساخت اتاق یا در حین برگزاری کلاس توسط ادمین.
* **احراز هویت امن و ساخت انحصاری اتاق توسط ادمین:** تنها مدیر سیستم با نام کاربری و کلمه عبور می‌تواند اتاق جدید تعریف کند.
* **لینک دعوت اختصاصی برای هر اتاق:** ادمین با یک کلیک لینک دعوت اختصاصی دریافت کرده و در اختیار دانشجویان یا شرکت‌کنندگان قرار می‌دهد.
* **اتاق انتظار و صف تایید ورود (Waiting Room):** شرکت‌کنندگان با ورود به لینک، نام خود را تعیین کرده و در اتاق انتظار قرار می‌گیرند تا مدیر تایید کند.
* **موتور پادهای ادوبی کانکت (Pod Engine):**
  * بوم تعاملی با قابلیت جابجایی (Drag)، تغییر اندازه (Resize) و چیدمان‌های پیش‌فرض (**Sharing**، **Discussion**، **Collaboration**).
  * حالت **Prepare Mode** برای تنظیم خلوت چیدمان توسط مدیر قبل از انتشار همگانی.
* **تخته سفید و حاشیه‌نویسی اسناد (Whiteboard & Document Viewer):**
  * ارسال تغییرات و رسم خطوط بر بستر کانال داده زنده UDP یا وب‌سوکت.
  * همگام‌سازی کامل صفحات و زوم ارائه اسلایدهای PDF.
* **مدیریت دسترسی‌ها و حاضرین (Attendee Pod):** تفکیک اعضا به Host (مدیر)، Presenter (ارائه‌دهنده) و Participant (شرکت‌کننده) با کنترل دسترسی وبکم، میکروفون، تخته و چت.
* **گفتگو (Chat Pod)، نظرسنجی زنده (Polls) و یادداشت‌ها (Notes Pod)**.

## ⚡ معماری شبکه: انتقال بر بستر UDP و WS

مرورگرهای امروزی برای انتقال UDP از پروتکل‌های **WebRTC (SRTP/UDP)** و **RTCDataChannel (SCTP/DTLS/UDP)** استفاده می‌کنند. در این سامانه:

1. **انتقال صدا (Audio Transport):**
   * **حالت UDP (پیش‌فرض):** ارسال جریان صوتی کدگذاری‌شده با Opus بر بستر RTP/UDP بدون تاخیر با FEC داخلی.
   * **حالت WS (TCP):** انتقال پایدار از طریق سوکت TCP در شبکه‌های دارای محدودیت UDP.
2. **انتقال تصویر و وبکم (Video Transport):**
   * **حالت UDP:** انتقال زنده تصویر وبکم با بالاترین نرخ فریم و بدون بافرینگ.
   * **حالت WS:** ارسال فریم‌ها بر بستر TCP.
3. **تخته سفید و سیگنالینگ لحظه‌ای (Data Channel):**
   * **حالت UDP:** ارسال نقاط قلم، پاک‌کن و نشانگر مختصات روی `RTCDataChannel` با فلگ `{ ordered: false, maxRetransmits: 0 }` که عملکرد مستقیم UDP روی کانال زنده را تامین می‌کند.
   * **حالت WS:** ارسال داده‌ها بر روی WebSocket امن سرور.
4. **سرور بومی UDP Socket در بک‌اند:**
   * سرور بک‌اند چابکان دارای سوکت محلی UDP بر روی پورت `3001` (با استفاده از ماژول `dgram` در Node.js) است که قابلیت تست پینگ و تبادل داده با کلاینت‌های دسکتاپ (Tauri) را به طور بومی فراهم می‌سازد.

## 🔒 نحوه کارکرد سیستم

1. **ورود ادمین و ساخت کلاس:**
   * ادمین با نام کاربری (`admin`) و رمز عبور (`admin123` یا متغیرهای محیطی) وارد پنل مدیریت می‌شود.
   * ادمین عنوان کلاس را تعیین کرده و پروتکل‌های دلخواه (صدا: UDP/WS، تصویر: UDP/WS، تخته: UDP/WS) را تنظیم می‌کند.
   * پس از زدن دکمه ساخت اتاق، یک شناسه اختصاصی و **لینک دعوت** تولید می‌شود (مانند `https://domain.com/?room=room-xyz`).
2. **ورود شرکت‌کنندگان:**
   * شرکت‌کننده لینک را باز کرده و عنوان اتاق و پروتکل‌های فعال را مشاهده می‌کند.
   * نام و نام خانوادگی خود را وارد کرده و درخواست ورود را ثبت می‌کند.
   * شرکت‌کننده در **اتاق انتظار (Waiting Room)** قرار می‌گیرد.
3. **تایید توسط مدیر:**
   * در پاد Attendee و نوار اعلان مدیر، درخواست ورود با نام کاربر نمایش داده می‌شود.
   * مدیر با کلیک روی **«تایید»** به کاربر اجازه ورود می‌دهد (امکان تایید دسته‌جمعی نیز وجود دارد).
   * به محض تایید، شرکت‌کننده وارد کلاس شده و پادها و جریان‌های صوتی/تصویری متصل می‌شوند.

## 🇮🇷 آموزش استقرار روی سرویس ابری چابکان (Chabokan.net)

[چابکان (Chabokan.net)](https://chabokan.net/) پلتفرم ابری کانتینری و سرورلس ایرانی است که پینگ تک‌رقمی، ترافیک نیم‌بها و پایداری کامل در شبکه داخلی را تضمین می‌کند.

### مراحل استقرار در چابکان با Docker:

1. وارد پنل کاربری در [Chabokan.net](https://chabokan.net/) شوید.
2. روی **«ایجاد سرویس جدید»** کلیک کرده و گزینه **برنامه با داکر (Docker)** را انتخاب کنید.
3. مخزن گیت این پروژه را متصل کنید.
4. مسیر فایل داکر را `Dockerfile` ریشه پروژه قرار دهید.
5. **تنظیمات پورت:**
   * پورت وب و وب‌سوکت: `3000` (HTTP / TCP)
   * پورت انتقال زنده UDP: `3001` (UDP)
6. **متغیرهای محیطی (Environment Variables):**
   ```env
   PORT=3000
   UDP_PORT=3001
   NODE_ENV=production
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=your_secure_password
   JWT_SECRET=your_jwt_secret_token
   ```
7. در بخش دیسک‌های ماندگار (Persistent Volumes)، مسیر داده‌ها `/app/data` و `/app/recordings` را برای ذخیره کلاس‌ها و ضبط‌ها اضافه کنید.
8. گواهی SSL رایگان دامنه را در پنل چابکان فعال کرده و سرویس را مستقر کنید.

سامانه به طور کامل آماده استفاده است و فرانت‌اند به صورت خودکار به دامنه چابکان متصل می‌شود.

## 💻 تست و اجرای محلی

### با Docker Compose:
```bash
docker compose up --build
```
سپس به آدرس [http://localhost:3000](http://localhost:3000) بروید.

### اجرای تفکیک‌شده برای توسعه:

1. **اجرای بک‌اند (Node.js + UDP + WebSockets):**
   ```bash
   cd chabokan
   npm install
   npm run dev
   ```
   تست‌های جامع سرور:
   ```bash
   npm test
   ```

2. **اجرای فرانت‌اند (Vite + React + Tailwind):**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

## 🖥️ تولید خروجی نصبی ویندوز (Tauri v2)

اپلیکیشن ویندوز با فریمورک پرسرعت **Tauri v2** آماده شده است که از WebView2 بومی ویندوز بهره برده و حجم فایل نصبی کمتر از ۱۵ مگابایت دارد:

```bash
cd frontend
npm run tauri build
```
فایل‌های خروجی نصبی در مسیر `src-tauri/target/release/bundle/msi` تولید خواهند شد.
